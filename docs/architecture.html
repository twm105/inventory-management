Filter Data Flow

User
FilterBar interaction
User selects period, warehouse, category, or order status in FilterBar.vue
Composable
useFilters.js — singleton reactive state
All views share the same composable instance. Filter values are ref()s; changing one triggers all watchers across every view simultaneously.
API Client
api.js — axios wrapper
Each view calls the relevant api.js method. Values equal to 'all' are omitted from query params so the backend returns unfiltered data for that dimension.
Backend
FastAPI — apply_filters() + filter_by_month()
Filters are applied to in-memory list copies (no mutation). Month filter supports plain months (YYYY-MM) and quarters (Q1–Q4). Inventory does not support the month dimension.
View
Vue refs + computed properties
Raw responses stored in ref() (e.g. allOrders). All displayed/derived data lives in computed() — never mutate raw refs directly.
